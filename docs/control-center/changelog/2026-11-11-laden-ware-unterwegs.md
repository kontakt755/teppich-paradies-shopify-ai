- **Geaendert:** Die Ansicht Laden (`#/laden`) zeigt unter den beiden Spalten den Abschnitt „Ware unterwegs“: je Lieferantenrechnung der letzten 7 Tage eine Zeile „<Lieferant>: Rechnung vom <Datum> da, Ware vermutlich verladen“, mit Bestellnummer oder Kommission aus dem Betreff, wenn vorhanden (Inhaber 11.11.2026: Rechnungen gehen nie ans Laden-Postfach, bedeuten aber meist „verladen“). Kein neuer Postfachabruf: Quelle ist die Lieferbeleg-Ablage des stündlichen Laufs. Es zählen nur Absender, die die privaten Stammdaten oder eine Entscheidung im Reiter „Belege“ einem Lieferanten zuordnen; Gutschrift, Mahnung und Storno zählen nicht. Kein Betrag, kein Anhang, kein Mailtext. „Gesehen“ blendet eine Zeile aus (gleiche Ablage wie „Telefonisch erledigt“). Es wird keine Mail versendet.
- **Getestet:** `docs/ai-dashboard/tests/laden.test.mjs` (2 neue Tests: Auswahl, 7-Tage-Fenster, Bezug, kein Betrag; API ohne Stammdaten, mit Dienstleister-Absender, Abhaken, beschädigte Ablage). `npm run -s pruefen`, `npm run dashboard:pruefen` (Desktop und 390 px).
- **Risiken/Annahmen:** „Vermutlich verladen“ ist eine Faustregel, kein Beleg. Die Zeilen sind höchstens so frisch wie der stündliche Beleg-Lauf (der Stand steht im Abschnitt). Rechnungen von Lieferanten, deren Absenderdomain in den Stammdaten fehlt, erscheinen nicht, bis sie dort oder im Reiter „Belege“ zugeordnet sind. Steht ein Dienstleister als Lieferant in den Stammdaten, erscheint auch seine Rechnung.

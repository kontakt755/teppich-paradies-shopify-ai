## 2026-11-13 · Ausschreibungen: dtvp.de als weitere Quelle

- **Geaendert:** Die wöchentliche Suche liest zusätzlich die öffentliche Liste von dtvp.de für Bodenverlege- und Bodenbelagsarbeiten (CPV 45432100 samt Untercodes, ohne Anmeldung, neueste zuerst) so weit zurück wie `--tage`. Übernommen werden offene Ausschreibungen, deren Titel oder Vergabestelle Berlin, Brandenburg oder einen Ort im Umkreis nennt. Steht dieselbe Bekanntmachung schon aus einer anderen Quelle in der Liste, ergänzt dtvp.de nur die fehlende Frist. Treffer von dtvp.de bleiben wie die aus dem Berliner Feed bis zur Frist stehen. Anlass: dtvp.de bietet Suchprofile und Benachrichtigung nur im bezahlten Tarif; das ist der kostenlose Ersatzweg.
- **Getestet:** `operations/tests/ausschreibungen.test.mjs` (neuer Fall dtvp.de mit einer Antwort im Aufbau vom 13.11.), `npm run -s pruefen`, Probelauf `npm run ausschreibungen:pruefen -- --tage 14`. Abgleich vorab: Von 35 Bodenbelags-Ausschreibungen der letzten zwei Wochen bei dtvp.de standen 28 im Export des Bundes, 7 nicht.
- **Risiken/Annahmen:** Die Liste nennt keinen Ort, Details stehen hinter der Anmeldung: Die Region wird nur am Namen erkannt. Eine Vergabestelle ohne Ortsnamen (etwa ein Institut in Potsdam-Golm) fällt durch, ein Auftrag irgendwo in Brandenburg wird gezeigt. robots.txt von dtvp.de erlaubt den Abruf; die Nutzungsbedingungen verbieten systematische Abrufe für eigene kommerzielle Angebote, nicht zur eigenen Information (eigene Lesart). Abruf einmal je Woche, drei bis fünf Seiten mit Pause, eigene Kennung. Die Umkreissuche von dtvp.de (PLZ und Radius) läuft nur über die Sitzung eines Browsers und wird nicht automatisch abgerufen.
- **Nächste Stufe:** Den Link zur fertigen Umkreissuche (100 km um Oranienburg) in die Ansicht „Neue Aufträge“ legen, damit ein Klick je Woche den Rest abdeckt.

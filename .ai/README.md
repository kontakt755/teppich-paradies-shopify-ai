# Router Memory

`AGENTS.md` bleibt die verbindliche Projektanweisung. Dieser Ordner ist ein kleines, selektiv lesbares Gedächtnis für Router und Worker – kein zweites Regelwerk und kein Obsidian-Vault.

Lesereihenfolge: zuerst `AGENTS.md`, danach nur die für den Task nötige Datei hier. Keine Secrets, Rohlogs, Kundendaten oder vollständigen Prompts speichern. Session-Notizen nur bei Entscheidungen oder echten offenen Punkten anlegen.

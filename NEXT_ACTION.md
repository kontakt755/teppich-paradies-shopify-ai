# Next Action

`npm run workflow:next` ausführen und ausschließlich dessen aktuelle, abgeleitete `NEXT_ALLOWED_ACTION` befolgen. Die nächste Aktion nicht manuell in dieser Datei nachführen. `workflow:continue` darf nur diesen sicheren Schritt ausführen oder den benötigten Agent, lokalen Mac-Runner beziehungsweise Human Gate melden.

Diese Datei speichert niemals eine Merge-, Preview- oder Live-Freigabe. Human Approval muss am jeweiligen Gate neu und ausdrücklich erfolgen.

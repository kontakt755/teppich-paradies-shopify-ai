FUNKTIONALITÄTEN (8 PRIMÄRE FUNKTIONEN)
================================================================================

1. LOAD_TEMPLATE(path)
   ├─ Lädt Excel-Vorlage
   ├─ Prüft Existenz
   └─ Gibt Workbook zurück

2. SET_MONTH_YEAR(ws, year, month)
   ├─ Setzt D3 (Jahr)
   └─ Setzt E3 (Monat)

3. GET_BRANDENBURG_HOLIDAYS(year, month)
   ├─ Holt Feiertage für Bundesland
   └─ Gibt {Tag: Name}-Dict zurück

4. READ_ABSENCES_FROM_FILE(path, year, month)
   ├─ Parst CSV-Datei
   ├─ Filtert nach Zielmonat
   └─ Gibt {employee: [(day, type, hours)]}-Dict zurück

5. GENERATE_HOURS_FOR_EMPLOYEE(employee, year, month, holidays, absences)
   ├─ Generiert realistische Stunden
   ├─ Prüft Maximalstunden
   ├─ Prüft Wochenlimit (40:00)
   └─ Gibt {day: {work, leave, holiday, sick, other}}-Dict zurück

6. WRITE_DATA_TO_WORKSHEET(ws, year, month, data, holidays)
   ├─ Schreibt Arbeitszeit (Zeile 14)
   ├─ Schreibt Urlaub (Zeile 15)
   ├─ Schreibt Feiertage (Zeile 16)
   ├─ Schreibt Krankheit (Zeile 17)
   └─ Schreibt Sonstige (Zeile 18)

7. VALIDATE_WORKBOOK(ws, year, month, employee, data)
   ├─ Prüft Maximalstunden
   ├─ Prüft Wochenlimit
   ├─ Prüft VMA-Konsistenz
   ├─ Zählt Tage & VMA-Tage
   └─ Gibt Validierungs-Report zurück

8. CREATE_VMA_FILE(template, employee, year, month, output_dir, absences)
   ├─ Kombiniert 1–7
   ├─ Speichert Excel
   └─ Gibt Report zurück

================================================================================
STUNDEN-FORMAT: HH,MM (NICHT Dezimalstunden!)
================================================================================

Das System verwendet die deutsche Schreibweise:

8,00  = 8 Stunden 0 Minuten
8,30  = 8 Stunden 30 Minuten
8,35  = 8 Stunden 35 Minuten
8,50  = 8 Stunden 50 Minuten
9,10  = 9 Stunden 10 Minuten

WICHTIG: Beim Addieren:
  8,50 + 0,20 = 9,10  ✓ (nicht 8,70)
  8,35 + 8,35 = 17,10 ✓ (nicht 16,70)

Intern rechnet das System in Minuten und konvertiert zurück.

================================================================================
EXCEL-STRUKTUR (UNVERÄNDERT)
================================================================================

Das System verändert NUR die Eingabefelder:

Zeile 3:  D = Jahr, E = Monat (WERDEN GESETZT)
Zeile 12: Tagnummern (Formel – unverändert)
Zeile 13: Wochentage (Formel – unverändert)
Zeile 14: Arbeitszeit (EINGABE – wird befüllt)
Zeile 15: Bezahlter Urlaub (EINGABE – wird befüllt)
Zeile 16: Feiertage (EINGABE – wird befüllt)
Zeile 17: Krankheit (EINGABE – wird befüllt)
Zeile 18: Sonstige Fehlzeiten (EINGABE – wird befüllt)
Zeile 20: VMA-Tag (Formel – unverändert, automatisch)
Zeile 21: VMA € (Formel – unverändert, automatisch)

VMA-Formel (Zeile 20):
  Wenn Arbeitszeit > 8,00 → dann 1 → dann 14€ in Zeile 21

## Executive Summary

This task implements the menu structure corrections identified in SHP-012. The primary objective is to add direct navigation links to high-value carpet sub-categories (Hochflor, Schlinge) that are currently missing from the main menu, reducing click depth and improving product discoverability.

---

## 1. Remediation Targets

### 1.1 Primary Objective: Add Carpet Sub-Categories

**Current State (from SHP-012):**
- Main menu (`main-menu`) contains only generic "Teppichboden" entry pointing to `/collections/teppichboden`
- Users cannot directly navigate to Hochflor or Schlinge carpet categories
- Sub-categories require multi-step navigation: Teppichboden → filter/browse

**Target State (SHP-013):**
Transform flat "Teppichboden" entry into hierarchical menu structure:

```
Teppichboden (parent, no direct action)
  ├── Hochflor (/collections/teppichboden-hochflor)
  ├── Schlinge (/collections/teppichboden-schlinge)
  └── [Optional] View All (/collections/teppichboden)
```

**Menu Handle:** `main-menu`  
**Items to Create:**
1. **Parent Item:** "Teppichboden" (transforms current link to parent-only)
2. **Child Item 1:** "Hochflor" → `/collections/teppichboden-hochflor`
3. **Child Item 2:** "Schlinge" → `/collections/teppichboden-schlinge`

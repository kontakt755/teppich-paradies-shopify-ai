## 6. Structural Discrepancies & Findings

### Finding 1: Missing High-Value Carpet Categories

**Severity:** MEDIUM  
**Category:** Completeness  

The main navigation omits direct links to two key carpet sub-categories:
- **Teppichboden-Hochflor** (`/collections/teppichboden-hochflor`) — High-pile carpets
- **Teppichboden-Schlinge** (`/collections/teppichboden-schlinge`) — Loop-pile carpets

**Impact:**
- Users must navigate to Teppichboden parent, then filter/browse sub-categories
- Reduces direct discoverability
- Increases click depth for these high-value product categories

**Remediation (SHP-013):**
These categories are flagged for addition in the linked task **SHP-013: Teppichboden-Menü korrigieren**, which will add "Hochflor" and "Schlinge" as sub-items under a "Teppichboden" parent link.

### Finding 2: URL Pattern Inconsistency (Low Risk)

**Severity:** LOW  
**Category:** Standardization  

The `hauptnavigation-2026` menu uses fully qualified URLs for collection links:
- Current: `/collections/vinylboden-1` (relative)
- 2026: `https://www.teppich-paradies.net/collections/vinylboden-1` (absolute)

Both patterns work, but the migration to 2026 menu introduces a minor inconsistency.

**Remediation:**  
Standardize to relative URLs in the 2026 menu for consistency and portability.

### Finding 3: Empty Menu (farbe)

**Severity:** LOW  
**Category:** Hygiene  

Menu `farbe` (handle: `farbe`) has no items assigned. 

**Possible Causes:**
- Leftover from previous experiments
- Unused placeholder for future feature
- Legacy artifact from menu management changes

**Remediation:**  
Delete or assign items if this menu is intended for production use.

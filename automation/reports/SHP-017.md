## 6. Rollback Plan

**If theme rendering breaks:**

1. **Quick Revert:** Revert Liquid template changes
   ```bash
   git revert <commit-sha>
   git push origin main
   ```

2. **Partial Rollback:** Keep collection, remove theme customizations
   - Comment out hero section in `collection.liquid`
   - Comment out Sisal badge in `product.liquid`
   - Keep care instructions (non-breaking)

3. **Collection Removal (Full Rollback):**
   - Delete `sisal-natur` collection in Shopify Admin
   - Revert navigation menu changes

**Rollback Window:** 15 minutes (during active store hours)

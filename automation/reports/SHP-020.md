## 3. Image Metadata Analysis

### 3.1 Filename Patterns

**Shopify Pattern (Most Common):**
```
{NUMERIC_ID}-{CODE_SUFFIX}-prod.jpg
Examples:
  - 1276693-8FXC-prod.jpg
  - 1196472-8FXC-prod.jpg
```
**Pattern:** Sequential numeric ID + vendor/product code suffix + "prod" designation
**Consistency:** HIGH — 15/17 follow this pattern
**Implication:** Likely generated by Shopify upload process or supplier system

**Alternative Patterns (Minority):**
```
Descriptive naming:
```

**Consistency:** LOW — Only 2/17 follow custom naming

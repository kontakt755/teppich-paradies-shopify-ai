```graphql
  }
}
```

### Step 2: Query Current Collection Membership

**Action:** For each collection, retrieve currently assigned products

```graphql

    products(first: 10) {
      edges {
        node {
          id
          title
          handle
        }
      }
    }
  }
}
```

**Record Current State:** Document before/after assignment to enable rollback if needed

---

### Step 3: Assign Products to Collections

**Approach:** Use Shopify Admin API `collectionPublish` mutation or Admin UI bulk edit

**GraphQL Mutation Example:**
```graphql
mutation {
  collectionAddProducts(input: {
    id: "gid://shopify/Collection/..."
    productIds: [
      "gid://shopify/Product/...",  # Piumera
      # additional product IDs
    ]
  }) {
    collection {
      id
      handle
      products(first: 10) {
        totalCount
      }
    }
    userErrors {
      field
      message
    }
  }
}
```

**Batch Strategy:** Assign products in 2 batches to ensure atomicity:
- **Batch 1 (Ready Collections):** Velours (7) + Nadelvlies (2) + Schlinge (4) = 13 products
- **Batch 2 (Blocked Collection):** Hochflor (1 ACTIVE) — hold until AW Ganges/Floresta published

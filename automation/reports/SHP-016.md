## Executive Summary

This specification finalizes the taxonomy, eligibility rules, and content guidelines for the **Sisal & Natur** product category. Based on product-level evidence (material descriptions, tags, benchmarking against industry standards), this document establishes:

1. **Definitive Rules:** Which products qualify for Sisal & Natur category
2. **Eligibility Criteria:** Evidence standards required for material classification
3. **Ambiguous Cases:** Products requiring manufacturer clarification before assignment
4. **Content Guidelines:** SEO, descriptions, and messaging for the category

**Key Decision:** Only products with **explicit 100% natural fiber documentation** are eligible for Sisal & Natur category.

### 1.2 Teppich Paradies Category Structure

**Proposed Hierarchy:**
```
Teppichboden (Root)
├── Hochflor
├── Velours/Samtdesign
├── Schlinge (Loop-Pile) — general synthetics
├── Nadelvlies (Flat/Contract)
├── Sisal & Natur ← NEW (Natural fibers only)
└── Wolle (Wool products, maintained as separate)
```

**Rationale:** Natural fiber category separated from synthetic & wool due to:
- Distinct purchasing motivation (eco, sustainable, natural aesthetics)
- Different cleaning/care requirements
- Premium positioning vs. standard carpet
- SEO differentiation

## 2. Eligibility Rules & Material Classification

### 2.1 Sisal Category Qualification (Tier 1: Definitive)

**Rule:** Product qualifies for **Sisal & Natur** if:
- ✅ Material description explicitly states **"100% Sisal"** OR
- ✅ Product tag includes `material: sisal` AND description confirms composition

**Evidence Hierarchy (Highest to Lowest Priority):**
1. **Product Description Text:** "Material 100% Sisal" (strongest evidence)
2. **Public Product Tags:** `material: sisal` (strong evidence)
3. **Product Title:** "Sisal Teppichboden" (supporting evidence)
4. **Collection Name:** "Sisal-Kollektion" (weak evidence, insufficient alone)
5. **Manufacturer Claim:** Unverified (requires documentation)

### 2.2 Wool Category Classification (Tier 1: Definitive)

**Rule:** Product remains in **Wolle** if:
- ✅ Material description explicitly states **"100% Schurwolle"** OR **"100% Virgin Wool"**
- ✅ Product tag includes `material: wool` AND description confirms fiber type

**Dual Classification Allowed:**
- Wool products **retain secondary classification** (e.g., "Schlinge", "Velours") to preserve surface-structure differentiation
- Primary category: **Wolle**
- Secondary categories: Surface construction (Schlinge, Bouclé, Velours)

### 2.3 Ambiguous Cases (Tier 2: Requires Manufacturer Verification)

**Rule:** Products with unclear material composition are **NOT assigned** to Sisal or Wool categories until evidence is verified.

**Evidence Gaps That Trigger Ambiguity:**
- Collection name mentions material (e.g., "Wool & Sisal") but actual product composition is not documented
- Product description missing or vague ("natural fibers" without specific percentages)
- Tags present but descriptions don't confirm exact composition

**Required Action:** Contact manufacturer for:
- Exact fiber percentage breakdown (e.g., "50% wool, 50% sisal")
- Material origin (virgin wool? Recycled? Biodegradable sisal?)
- Care label specifications
- Certification claims (organic, fair trade, etc.)

## 4. Content Specifications

### 4.1 Collection Metadata

**Collection Name:** Sisal & Natur  
**Handle:** `sisal-natur`  
**Type:** Manual (not automated by rule)

**SEO Title:**  
```
Sisal Teppichboden als Meterware | Teppich Paradies
(Max 60 chars for Google SERP)
```

**Meta Description:**  
```
Sisal-Teppichboden als natürliche Meterware entdecken. Farben und 
Rollenbreiten vergleichen, Muster bestellen und persönlich beraten lassen.
(Max 160 chars)
```

**Collection Description (Internal):**  
```
Sisal-Teppichboden verbindet eine natürliche Faser mit einer markanten, 
robusten Oberfläche. Entdecken Sie passende Farben und Rollenbreiten für Ihr Projekt.
```

### 4.3 Care & Installation Messaging

**Sisal-Specific Guidance:**
```
**Pflege:**
- Regelmäßig absaugen (kein Nasssauger)
- Bei Verschüttungen sofort mit trocknem Tuch aufnehmen
- Professionelle Reinigung empfohlen (mindestens 1x jährlich)
- Nicht für feuchte Räume geeignet

**Installation:**
- Fachgerechte Verlegung erforderlich (Verlegungspartner empfohlen)
- Untergrund muss trocken und eben sein
- Akklimation vor Verlegung: 48 Stunden
```

**Wool-Specific Guidance:**
```
**Pflege:**
- Regelmäßig absaugen
- Fleckenentfernung: Spezialist Teppichreiniger verwenden
- Jährliche professionelle Reinigung empfohlen
- Sehr langlebig: 10-20 Jahre Lebensdauer

**Installation:**
- Standard Verlegung (Klebe oder Dehnfixierung)
- Akklimation: 24-48 Stunden
```

### 5.2 Validation Rules (for CSV validator tool)

**Rule 1: Material Evidence Required**
```
IF assignment_status = "READY"
THEN evidence_type IN ("PDP + Tags", "PDP + Description", "Explicit 100%")
```

**Rule 2: No Invented Attributes**
```
IF material_composition CONTAINS ("Unknown", "Unclear", "Mixed")
THEN assignment_status != "READY"
```

**Rule 3: Dual Category Logic**
```
IF primary_category = "Wolle"
THEN secondary_categories MAY INCLUDE ("Schlinge", "Velours", "Bouclé")
ELSE secondary_categories MUST BE empty OR "Teppichboden" only
```

**Rule 4: Collection Consistency**
```
IF assignment_status = "READY"
THEN product_handle MUST BE added to corresponding collection
ELSE product_handle REMAINS in "Teppichboden" only
```
